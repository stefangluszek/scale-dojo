# Live practice

Reserved for stage 2. Live listening and note feedback are not implemented in the bootstrap.

Combine stable pitch observations with the selected scale to display the current note, confidence, and in-scale/off-scale feedback. Use the browser audio adapter rather than acquiring the microphone in visual components. Keep note stabilization and classification testable without a physical microphone; silence is not an incorrect note.
