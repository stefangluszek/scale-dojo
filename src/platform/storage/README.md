# Browser storage boundary

Reserved for stage 3. Nothing is persisted in the bootstrap.

Own versioned serialization, storage access, and recovery from unavailable or malformed data here. Session capture and scale classification belong to features and domain code. Store detected note events by default; raw audio persistence is a separate product decision.
