# Scale Dojo

<img src="public/favicon.svg" alt="Scale Dojo logo" width="64" height="64" align="right" />

Practice bass scales in your browser. Explore notes on a fretboard, hear a scale, and use your microphone for live note feedback and a saved practice review.

**[Open Scale Dojo →](https://stefangluszek.github.io/scale-dojo/)**

Standard four-string bass, with major, natural minor, and pentatonic scales. No account needed: audio is processed on your device, and detected notes and settings are saved in this browser. Raw audio is never saved or sent.

## Run locally

Use Node.js 24.15+ (24.x) and npm.

```sh
npm ci
npm run dev
```

Open the URL printed by Vite, including `/scale-dojo/`.
